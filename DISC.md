# Which disc works

This port is compiled from the European PlayStation release of Medal of Honor.
It only runs with a dump of that disc:

| | |
|---|---|
| Redump set | Medal of Honor (Europe) |
| Serial | SLES-02470 |
| Files | `Medal of Honor (Europe).cue` + `Medal of Honor (Europe).bin` (one track) |
| Size of the .bin | 741,980,736 bytes |
| CRC32 | `e5070481` |
| MD5 | `5e2c8aaba7c3b939093584deb84711c8` |
| SHA-1 | `8c2e96724118908833d0ca485760dd208238aa87` |

Select the `.cue` on first start. The USA (SLUS-00974), French (SLES-02471)
and German (SLES-02472) discs have different contents (other checksums) and
are not supported: the precompiled code is bound to the European data track.

Dump your own disc; game images are not provided here.
